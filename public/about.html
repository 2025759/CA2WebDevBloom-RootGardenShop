About Bloom & Root

Bloom & Root Garden Shop is a full-stack e-commerce website developed as a Continuous Assessment project for the Web Development module on the H.Dip. in Computing programme at CCT College Dublin.

Purpose

The site demonstrates a simple online garden shop where customers can browse plants, pots and tools, manage a shopping cart, and complete checkout. Product data, prices and cart state are managed dynamically through a Node.js server connected to an SQLite database.

Technologies

  • HTML5 — semantic structure and accessible markup
  • CSS3 — responsive layout and styling
  • JavaScript — dynamic UI, API integration and form validation
  • Node.js & Express.js — REST API and static file serving
  • SQLite (sql.js) — products, cart, orders and market rate storage

Accessibility & Responsive Design

This website uses semantic HTML elements (header, nav, main, section, article, footer), skip navigation links, ARIA labels where helpful, and a responsive layout that works on mobile and desktop screens.

Features

  • Dynamic product loading from database via API
  • Server-managed shopping cart (add, update, remove)
  • Market rate price multiplier
  • Checkout with client and server validation
  • Order confirmation and database persistence
